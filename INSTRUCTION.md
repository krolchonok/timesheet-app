# Инструкция Timesheet

Краткое руководство для сотрудников и руководителя группы.

## Доступ

- **Расписание** (`/`) — открыто всем, без входа. Выберите ФИО и заполните табель.
- **Админ-панель** (`/admin`) — только по логину и паролю администратора.

## Роли

| Роль | Кто | Что делает |
|------|-----|------------|
| **user** | Сотрудник | Заполняет часы, создаёт задачи |
| **admin** | Руководитель | Смотрит заполнение, задаёт итоговое название и статус |

## Норма 40 часов

В норму входят **все** часы за неделю: проектная строка + все задачи, любой категории.

Индикатор: `Проект X · задачи Y · X+Y / 40 ч`.

## Сотрудник (user)

1. Открыть страницу → выбрать **ФИО** и **неделю** (вход не требуется).
2. **Проектные задачи** — вписать часы по дням (Пн–Пт).
3. **+ Задача** — новая задача: категория, название, часы, комментарий.
4. **Экспорт CSV** — выгрузка своих строк.

## Руководитель (admin)

### Просмотр

- **Кто заполнил** — сводка по 40 ч (проект + админ).
- Раскрыть сотрудника — таблица задач.
- **Проектные задачи** — первая строка, только часы.
- **Итоговое наименование** + кнопка **→** — перенести название задачи в итоговое поле.
- **Статус**: Новая → Редактируется → Перенесено.
- Категорию можно исправить, если сотрудник выбрал неверно.

### Управление

- **Сотрудники** — список ФИО для выбора в табеле.
- **Категории** — справочник для отчётных задач.

## MS Project

Экспорт CSV → импорт в MS Project (разделитель `;`, кодировка UTF-8).
